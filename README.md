## Setup (requires Node.js, PNPM and Unix)
```sh
git clone git@github.com:amendoa/amendoa.dev.git
cd amendoa.dev
make
```

## Running (dev)
```sh
pnpm dev
```

## Building (prod)
```sh
pnpm build
```
